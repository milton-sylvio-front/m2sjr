## Brand & Style

The design system projects elite technical mastery, precision engineering, and understated power. Built for a Senior Fullstack / Frontend Engineer, the aesthetic merges the razor-sharp utility of developer tooling with the luxury and spatial discipline of high-end editorial architecture.

The style fuses **Technical Brutalism** and **Atmospheric Glassmorphism**:
- Deep, near-black abyss surfaces create an endless stage.
- Hyper-saturated neon accents pierce the dark canvas with calculated intention.
- Monospaced data arrays meet architectural grotesque headlines, telegraphing high-throughput competence and sophisticated taste.
- Interaction states mimic illuminated phosphor displays, laser-cut borders, and subtle command-line telemetry.

## Colors

The palette relies on severe contrast between a deep oceanic obsidian and an electric, ionizing mint.

- **Primary (`#01FBA1` - Neon Mint):** Reserved for focal points, high-impact interactive calls to action, code anchors, and active metrics. Never used as large background fills; it serves as a concentrated light source.
- **Secondary (`#00A86B`):** Anchors hover progressions, secondary technical badges, and controlled gradients.
- **Tertiary (`#64FFDA`):** Provides a spectral shift for syntax highlighting, nested terminal outputs, and specialized status tags.
- **Neutral (`#012928` - Verde Abissal):** The core atmospheric substrate. Tonal tiers step from `#001413` (canvas void) up through `#012928` (base view) to `#023938` (elevated panels) and `#054D4B` (subtle structural borders).

## Typography

The typographic hierarchy pairs the contemporary, structural authority of **Hanken Grotesk** for high-impact statements with the computational clarity of **JetBrains Mono** for all narratives, data streams, and specifications.

- **Headlines & Titles:** Rendered in tight-tracked, weighty Hanken Grotesk, evoking architectural precision.
- **Narratives & Technical Metrics:** JetBrains Mono ensures that descriptions read like polished source code or technical blueprints. Generous line-height (`24px` on `14px` font) ensures effortless readability across dense architectural explanations.
- **Micro-labels & Indexing:** Rendered in all-caps JetBrains Mono (`label-caps`) with deliberate letter spacing (`0.08em`) to mimic terminal indicators and compiler flags (e.g., `[SYS.READY]`, `V2.4.0`).

## Layout & Spacing

The layout is built on a 12-column rigid grid framework structured with wide canvas gutters and clear technical cadence.

- **Grid Architecture:** 12-column setup for desktop screens (max content width `1280px`), adapting to 6 columns on tablet, and a single or dual-column structural stack on mobile.
- **Vertical Rhythm:** Strict multiples of `4px` and `8px`. Section transitions leverage `space-2xl` (`4rem`) to give projects room to breathe, establishing a museum-grade technical gallery.
- **Alignment:** Strictly structured along left axis baselines. Code listings, project cards, and metrics pin to identical outer bounding lines, reinforcing engineered discipline.

## Elevation & Depth

Rather than relying on generic drop shadows, depth is manifested through **layered obsidian surfaces**, **diffused neon bioluminescence**, and **etched borders**:

- **Layer 0 (Canvas Void):** `#001413` fills the outermost background.
- **Layer 1 (Substrate Panel):** `#012928` with a 1px border of `#054D4B` (40% opacity).
- **Layer 2 (Interactive Floating Card):** `#023938` overlaid with a backdrop blur (`blur(12px)`) and a subtle inner top highlight (`1px solid rgba(255, 255, 255, 0.05)`).
- **Luminescence / Accent Depth:** Hover and active focus states activate a localized phosphor bloom using `box-shadow: 0 0 24px -4px rgba(1, 251, 161, 0.22)`.

## Shapes

The interface embraces a strict, semi-industrial aesthetic with **Soft** geometry (`0.25rem` / `4px` base border radius).

- **Standard Containers & Buttons:** `rounded-sm` (4px). Curves are intentional and minimal, avoiding toy-like pill forms in favor of precision-milled hardware edges.
- **Cards & Modal Surface Sheets:** `rounded-lg` (8px max).
- **Interactive Badges / Counters:** Consistent 4px geometry, preserving alignment with monospaced character widths.

## Components

### Buttons
- **Primary:** Neon Mint background (`#01FBA1`), dark abyssal text (`#001413`), 4px radius, JetBrains Mono font-weight 600. On hover: shifts background to `#64FFDA` and deploys a concentrated perimeter glow (`0 0 16px rgba(1, 251, 161, 0.4)`).
- **Secondary / Ghost:** Transparent background with a `1px` border of `#054D4B` and text in `#F2FFFA`. On hover: border transitions to `#01FBA1` with an inner fill tint of `rgba(1, 251, 161, 0.06)`.
- **Command / Terminal Button:** Monospaced prefix (e.g., `$ ./view-architecture`) featuring an active blinking cursor block indicator.

### Project & Architecture Cards
- Built with a `#012928` surface, `1px solid #054D4B`, and 8px radius.
- Includes a top bar telemetry header displaying file metadata or tech stacks (e.g., `SYS // TYPESCRIPT // K8S`).
- Hover triggers a smooth 1px top-border gradient flare and elevates the title color to `#01FBA1`.

### Chips & Tech Badges
- Compact indicators with `0.25rem` radius, padded at `2px 8px`.
- Background set to `rgba(1, 251, 161, 0.08)`, border `1px solid rgba(1, 251, 161, 0.25)`, text in `#01FBA1` using `label-caps`.
- Status indicators feature an ambient pulsing live-dot (`4px` green indicator with a 2-second pulse animation).

### Terminal / Code Preview Blocks
- Surface `#001413` embedded with a subtle dot-grid or raster scanline overlay.
- Tabbed file navigation using `label-code` typography, with the active tab highlighted by a `2px` underline in `#01FBA1`.
- Clean monospaced line numbering tinted in `#4B736E`.

### Form Fields & Inputs
- Background in deep abyss `#011E1D`, bordered with `1px solid #054D4B`.
- Text color is `#F2FFFA`, placeholder text is `#4B736E`.
- Focus state instantly switches the border to `#01FBA1`, emitting a subtle inward field glow without expanding layout bounds.
